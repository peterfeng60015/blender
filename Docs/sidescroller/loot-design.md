狀態：**使用者已確認（2026-10-28）**，原話「都先按照你的建議」：第 8 節四點全部照建議。
依據：2026-10-28 使用者補充的遊戲設計。原話重點：「打死敵人會掉落素材和裝備」「背包設計參考暗黑破壞神，道具有格子佔位數」「身上滿了就不會自動撿」「裝備強化另外開闢一個介面」。

## 1. 道具種類

| 類別 | 佔格 | 堆疊 | 說明 |
|---|---|---|---|
| 零件（素材） | 1×1 | 每格 20 | 強化用的唯一素材 |
| 近戰武器（揮砍類） | 2×3 | 不可 | 例：郵差包、捲筒報紙、長柄雨傘 |
| 遠程武器（弓箭類） | 2×3 | 不可 | 例：急件彈弓、快遞短弓、包裹十字弓 |
| 殼甲（滾殼） | 2×2 | 不可 | 例：殼帶護片、鋼板殼甲；影響滾殼與防禦 |

- 身上 3 個裝備欄：近戰、遠程、殼甲。對應現有的三種攻擊：J 揮砍、K 射擊、L 滾殼。
- 開場裝備：「破舊郵差包」（近戰，白色、沒有詞條）。遠程與殼甲欄在劇情 2 時發放「急件彈弓」「殼帶護片」，取代原本的 `grant` 指令。

## 2. 稀有度與詞條

| 稀有度 | 顏色 | 詞條數 | 掉落權重 |
|---|---|---|---|
| 普通 | 白 | 0 | 60 |
| 魔法 | 藍 | 1～2 | 30 |
| 稀有 | 黃 | 3～4 | 10 |

每件裝備有一個「基礎數值」（依種類固定），再從該類別的詞條池抽詞條，同一件不會重複抽到同一條：

| 詞條 | 可出現在 | 數值範圍 |
|---|---|---|
| 傷害 +N | 近戰、遠程 | +1～+2 |
| 攻擊速度 +N% | 近戰、遠程 | +10～25% |
| 攻擊範圍 +N% | 近戰 | +10～30% |
| 擊退強化 | 近戰 | 固定 |
| 射程 +N% | 遠程 | +15～40% |
| 多重射擊 +1 | 遠程 | 固定（稀有限定） |
| 穿透 | 遠程 | 固定（稀有限定） |
| 滾殼傷害 +N | 殼甲 | +1～+2 |
| 滾殼冷卻 −N% | 殼甲 | −10～25% |
| 最大血量 +1 | 殼甲 | 固定 |
| 受傷後無敵 +N 秒 | 殼甲 | +0.2～0.5 |
| 移動速度 +N% | 全部 | +5～12% |
| 零件掉落 +N% | 全部 | +10～30% |

- 數值取整後顯示，例如「傷害 +2」「攻擊速度 +18%」。
- 服裝（日班／特急）的數值差異保留，和裝備數值相加。

## 3. 掉落

| 敵人 | 零件 | 裝備機率 |
|---|---|---|
| 業務鼠 | 1～3 | 15% |
| 監工鴿 | 1～2 | 10% |
| 保全犀牛 | 4～6 | 60% |
| 河董（Boss） | 10 | 100%，稀有度至少魔法 |

- 裝備種類平均抽（近戰／遠程／殼甲各 1/3），稀有度照第 2 節的權重。
- **防刷**：死亡重生後敵人照樣重生，但已經打倒過的那一隻（依關卡資料的 id）不再掉落。
- 道具落地時有稀有度光柱（白／藍／黃），30 秒後消失；最後 5 秒閃爍。

## 4. 自動拾取與飛行

1. 敵人死亡 → 道具從死亡位置往上噴，落地彈一下（約 0.5 秒）。
2. 落地後判斷背包放不放得下：
   - **放得下**：先在背包預留位置（避免同時掉落的多件搶同一格），沿二次貝茲曲線飛向畫面右上角的背包圖示，約 0.6 秒，越飛越快、越飛越小。抵達時圖示跳一下，旁邊顯示「+3 零件」或裝備名稱（用稀有度顏色）。
   - **放不下**：留在地上，背包圖示閃紅並顯示「背包已滿」。玩家走到道具上自動撿（再判斷一次）；鍵盤／觸控不需要額外按鍵。
3. 零件優先疊到既有的未滿堆疊，滿了才佔新格。
4. 飛行中的道具不受暫停影響：開背包或暫停時直接放進背包。

## 5. 背包介面（I 鍵／觸控右上角圖示）

- 開背包時遊戲暫停。
- 左邊是 3 個裝備欄，右邊是 10×4 格子盤，下面顯示零件總數。
- 操作：
  - 滑鼠／手指：點起道具 → 點格子放下；放到被佔住的位置時，和那件交換（同暗黑）。拖曳也可以。
  - 拖到裝備欄＝裝上，換下的那件回到手上。
  - 拖到格子盤外＝丟到地上（要確認）。
  - 鍵盤：方向鍵移動游標，J 拿起／放下，E 直接裝上，Esc 關閉。
- 指到道具時顯示說明框：名稱（稀有度顏色）、種類、基礎數值、詞條、強化等級；指到背包裡的裝備時並列顯示目前身上那件做比較。

## 6. 強化介面（存檔點的補給站）

- 補給站在 cp1、cp2 旁邊，靠近時顯示「E：強化」（觸控顯示按鈕）。開介面時遊戲暫停。
- 左邊選裝備（身上 3 件＋背包裡的裝備），右邊顯示：

| 欄位 | 內容 |
|---|---|
| 目前等級 → 下一級 | 例：+2 → +3 |
| 下一級效果 | 基礎數值增加多少 |
| 需要零件 | 例：12（目前持有 34） |
| **成功率** | 大字顯示，例：60% |
| 失敗後果 | 例：「失敗：零件消耗，等級不變」 |

| 強化 | 需要零件 | 成功率 | 失敗 |
|---|---|---|---|
| +0 → +1 | 3 | 100% | — |
| +1 → +2 | 5 | 85% | 零件消耗，等級不變 |
| +2 → +3 | 8 | 65% | 零件消耗，等級不變 |
| +3 → +4 | 12 | 45% | 零件消耗，等級 −1 |
| +4 → +5 | 18 | 30% | 零件消耗，等級 −1 |

- 每升一級：武器基礎傷害 +1（偶數級）或攻擊速度 +5%（奇數級）；殼甲：滾殼傷害 +1／冷卻 −5% 交替。
- 按「強化」後有 0.6 秒的結果演出（成功金光／失敗灰煙），再顯示結果。
- 數字以程式裡的亂數決定，不做保底。

## 7. 保存

- 背包、裝備、零件、強化等級：整局有效，死亡重生不扣；回選單或「再玩一次」時清空。
- 不做永久存檔。

## 8. 使用者決定（2026-10-28，全部照建議）
