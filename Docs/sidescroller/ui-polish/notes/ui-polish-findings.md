## 畫面清單
選擇遊戲選單、開場演出對話框（narration）、HUD（心、裝備、提示條、背包圖示）、觸控按鈕、Boss 血條、

## 品質問題
1. **質感**：所有面板、按鈕都是純色直角矩形（洋紅、半透明白、深紫），沒有邊框、圓角／斜角、陰影、漸層；和場景的 90 年代動畫＋夕陽霓虹風格脫節，看起來像除錯介面。
2. **字**：只有一個字重，標題沒有描邊或陰影；疊在亮背景上的文字（提示條、Boss 名稱、按鈕字）對比不足；操作說明 22～28pt、45～60% 白，手機上幾乎讀不到。
3. **層級**：選單只有「選擇遊戲」標題＋一顆按鈕，畫面 80% 空白、沒有遊戲 Logo 或主視覺；通關畫面和暫停長得一樣，沒有慶祝感；強化介面「100%」字級突兀，下方有一條紅色殘影。
4. **按鈕**：未選中項是 6% 白底，幾乎看不出是按鈕；沒有按下回饋（縮放、亮度）；觸控按鈕是半透明白圓＋細字，在亮背景上看不清，和像素風的背包圖示風格不一致。
5. **版面**：右上暫停鈕、背包圖示、HUD 除錯計數器擠在一起；背包面板半透明，格子後面的場景透出來很雜；背包的「關閉」按鈕比標題還大；對話框占畫面下方約 1/3、純洋紅框。
6. **動畫**：除了字卡，所有面板瞬間出現／消失，沒有淡入、滑入或彈跳；選項切換沒有過場。
7. **其他**：IngameDebugConsole 的錯誤計數浮窗疊在畫面中間偏右（是否出現在正式版要確認）；HUD 在通關畫面仍顯示。

## 追加範圍（使用者經協調轉達：「UI優化也包括左邊的移動按鈕和右邊的數個功能按鈕」）
8. **觸控操作層**（`TouchControlsView`）：左側浮動搖桿只是兩個半透明圓；右側跳／甩包／彈弓／滾殼、右上暫停／換裝都是半透明白圓＋細字，
   亮背景上看不清、和像素風背包圖示不一致；按下只換顏色、沒有縮放回饋。改版要顧：大小（≥9mm）、熱區、按下回饋、半透明度不擋遊戲畫面、安全區。
